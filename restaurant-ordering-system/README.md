# Restaurant Ordering System

Expo (React Native) app for restaurant ordering, with Supabase and Stripe integration. Web-first setup.

## Prerequisites

- **Node.js v18+** — [Download](https://nodejs.org/)
- Verify: `node --version` and `npm --version`

## Quick Start

```bash
cd restaurant-ordering-system
npm install
npx expo start --web
```

Opens **http://localhost:8081** in your browser.

## Optional: Global CLI tools

```bash
npm install -g expo-cli eas-cli
expo --version
eas --version
```

You can also use `npx expo` and `npx eas-cli` without installing globally.

## Project setup (from your checklist)

This project was scaffolded with:

- **Expo** — React Native for web/iOS/Android
- **React Navigation** — `@react-navigation/native`, `@react-navigation/native-stack`
- **React Native Web** — `react-native-web`, `react-dom`, `@expo/metro-runtime`
- **Supabase** — `@supabase/supabase-js`
- **Stripe** — `@stripe/stripe-js` (web-only for now)
- **React Native Paper** — `react-native-paper`, `react-native-safe-area-context`
- **AsyncStorage** — `@react-native-async-storage/async-storage`
- **Vector Icons** — `@expo/vector-icons`
